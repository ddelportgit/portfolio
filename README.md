# Donovan Delport - Portfolio Website

> A modern, responsive personal portfolio website designed to showcase my skills, projects, and professional experience.

## 📖 Project Introduction

This repository contains the source code for my personal portfolio website. The goal of this project was to create a central hub where I can display my recent work, share my technical background, and provide an easy way for potential employers or clients to get in touch with me.

The site is built with a focus on performance, accessibility, and clean UI/UX design, ensuring a seamless experience across all devices.

## 🛠 Technologies Used

This project was built using the following technologies:

- **Frontend Framework:** React.js
- **Styling:** CSS Modules / Styled Components
- **Animations:** CSS Transitions
- **Icons:** FontAwesome
- **Deployment:** GitHub Pages
- **Version Control:** Git & GitHub

## ✨ Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
- **Project Showcase:** A dynamic grid displaying project thumbnails, descriptions, and links to live demos/source code.
- **Smooth Scrolling:** Seamless navigation between sections (About, Skills, Projects, Contact).
- **SEO Optimized:** Meta tags and semantic HTML implemented for better search engine ranking.
- **Fast Loading:** Optimized assets and lazy loading for images.

## ⚙️ Installation Instructions

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

- npm
  ```sh
  npm install npm@latest -g
  ```

### Steps

1. **Clone the repository:**
   ```sh
   git clone https://github.com/your-username/your-portfolio-repo.git
   ```
2. **Navigate to the project directory:**
   ```sh
   cd your-portfolio-repo
   ```
3. **Install dependencies:**
   ```sh
   npm install
   ```
4. **Start the development server:**

   ```sh
   npm start
   ```

   The site will open at `http://localhost:3000`.

5. **Build for production:**
   ```sh
   npm run build
   ```
